# Professional Identity & Claim Language

## Primary identity
**Backend Software Engineer** specialising in backend application development, reliable APIs, backend services and data-driven software systems.

## PortfolioPulse project description
“Independently designed and developed PortfolioPulse, a backend-focused portfolio reporting demonstrator using Python, FastAPI, SQLAlchemy and PostgreSQL. The project models organisation-scoped reporting workflows, validates CSV submissions, applies deterministic financial calculations, and exposes analytics through versioned REST endpoints. I use automated tests, migrations and Docker-based setup to make the implementation inspectable and reproducible.”

Use only the clauses that match the actual code and verification state at the time of publication.

## CV bullet template
“Built [specific capability] using [technology], handling [specific constraint]; verified through [test/demo/CI evidence].”

Example once verified:
“Implemented organisation-scoped CSV ingestion in FastAPI with row-level validation and duplicate protection; verified with integration tests covering valid, invalid and repeated submissions.”

Do not use this example until those tests pass.

## Interview introduction
“I’m a Software Engineer focused on backend application development. My work centres on Python APIs, relational data modelling, validation and reliable data workflows. PortfolioPulse is an independent project where I’m demonstrating those capabilities through a multi-organisation reporting API. I’m careful to distinguish what is implemented, what I have tested, and what remains a limitation.”

## Separate historical experience from independent proof
Describe the eight-month role with its true title, dates, responsibilities and supporting records. Describe PortfolioPulse separately as an independent engineering project. The connection may be “informed by problems I encountered”, but only if that is factually accurate and does not reveal confidential information.
